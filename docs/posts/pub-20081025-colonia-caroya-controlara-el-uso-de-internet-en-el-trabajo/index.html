una investigación que fue archivada por falta de pruebas y gestó la decisión

de las autoridades de instalar un sistema que permita controlar su uso.

Ante los hechos que son de público conocimiento, hemos consultado con la

Cooperativa y ellos están utilizando un sistema que les dio muy buenos

resultados ya que les permite controlar no sólo el tipo de páginas que se

consultan sino también la cantidad de tiempo que se demoran en cada una de

ellas, explicó el secretario de Gobierno, Luis Grión.
