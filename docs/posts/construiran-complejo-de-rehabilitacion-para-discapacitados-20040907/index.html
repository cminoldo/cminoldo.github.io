Construirán complejo de rehabilitación para discapacitados

Jesús María. La Municipalidad de Jesús María y el Club Argentino de Servicios firmaron un convenio de colaboración mutua para poner en marcha un complejo destinado a la rehabilitación y educación de personas con capacidades diferentes.

El convenio fue firmado por el intendente Marcelino Gatica, el secretario de Gobierno, Gabriel Frizza, y por Eladio Martínez, Jorge Gleria y Oscar Micolini, en nombre del Club Argentino de Servicios.

El municipio aportará la mano de obra y el club aportará para la adquisición de materiales para la concreción de este proyecto que implicará una inversión de 100 mil pesos, en la primera etapa. Además, se está gestionando apoyo nacional y provincial para el proyecto y se está organizando una cena de fin de año para recaudar fondos.

Paralelo a la firma del convenio, se creó una comisión entre las partes para coordinar las acciones para construir la sede, que dirigirá técnicamente la Secretaría de Desarrollo Urbano.
