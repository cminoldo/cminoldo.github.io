Inauguran ampliación de Complejo para la Discapacidad

Jesús María. Este martes, el municipio de esta ciudad inaugurará la segunda etapa del Complejo para la Discapacidad de barrio Latinoamérica donde se construyeron 149 metros cuadrados cubiertos con cuatro consultorios para usos múltiples, sanitarios para discapacitados y personal, y una sala de espera. Se invirtieron 117 mil pesos de fondos municipales.
