Reempadronamiento comercial

Jesús María. Desde julio, la Municipalidad de esa ciudad y el Centro Comercial e Industrial lanzarán la campaña de reempadronamiento comercial para corroborar las habilitaciones y la documentación necesaria para poder funcionar.

Jesús María. Desde julio, la Municipalidad de esa ciudad y el Centro Comercial e Industrial lanzarán la campaña de reempadronamiento comercial para corroborar las habilitaciones y la documentación necesaria para poder funcionar.

Inspectores municipales, debidamente identificados, recorrerán cada comercio completando una planilla donde registrarán los datos del titular, el nombre del negocio, la categoría, si posee libreta de sanidad al día, la cantidad de empleados, entre otros datos. También se corroborará si el rubro que poseen y el rubro en el que se habilitaron es el mismo.
