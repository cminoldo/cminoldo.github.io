Crean el Consejo Deliberante Estudiantil en Colonia Caroya

Colonia Caroya. El Concejo Deliberante de Colonia Caroya aprobó la ordenanza que establece la creación del Consejo Deliberante Estudiantil, un programa para incentivar la participación democrática de los jóvenes de la ciudad. El Consejo Estudiantil fue planteado como un espacio formal para que se analicen problemas y se gestionen sus posibles soluciones.
