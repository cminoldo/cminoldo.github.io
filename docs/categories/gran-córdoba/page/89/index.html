La UCR dice que no se pueden instalar tragamonedas

Colonia Caroya. El Comité de Circuito de la Unión Cívica Radical de Colonia Caroya señaló que existen motivos fundados y suficientes para que no se pueda instalar ningún tipo de sala de juego con máquinas tragamonedas o slots dentro del ejido municipal. La afirmación está fundada en el Código de Espectáculos Públicos que se sancionó en 1997.
